# Meu diário de humor

Registro diário de humor para acompanhamento psicológico entre sessões.
Psicóloga responsável: Milena Thaís Machado, CRP 07/46878.

## O que a paciente registra
- Clima do dia e emoções sentidas
- Energia e ansiedade (escala de 0 a 5)
- Sono (horas e qualidade), alimentação e medicação
- Pequenos cuidados do dia e uso de álcool ou substâncias
- Funcionamento cotidiano
- Pergunta de segurança, com orientação de ajuda (CVV 188, SAMU 192) quando a resposta não é "Não"
- Texto livre: o que mexeu, o que ajudou e o que levar para a sessão

O histórico mostra os últimos 14 dias por cor, um resumo da semana e permite copiar os registros para enviar à psicóloga.

## Privacidade
Os dados ficam salvos apenas no navegador do aparelho da paciente (localStorage). Nada é enviado a servidores. Registros feitos na versão anterior são migrados automaticamente.

## Como publicar no GitHub Pages
1. Crie um repositório novo no GitHub (por exemplo, `diario-de-humor`).
2. Envie os arquivos `index.html` e `README.md` (botão **Add file > Upload files**).
3. Vá em **Settings > Pages**, em *Source* escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`, e salve.
4. Em um ou dois minutos o link fica disponível em `https://SEU-USUARIO.github.io/diario-de-humor/`.

Dica para a paciente: abrir o link no celular e usar "Adicionar à tela de início" para ter o diário como um app.
